# Promo ENI — EDWM2605FT

Site de présentation de ma promotion, réalisé en HTML / CSS / JavaScript
vanilla dans le cadre de la formation **Développeur Web et Web Mobile (ENI)**.

---

## Fonctionnalités

- **Accueil** : présentation de la formation
- **Informations** : détails sur le programme et les apprenants
- **Carte** : carte interactive ([Leaflet](https://leafletjs.com/) +
  OpenStreetMap) situant chaque apprenant de la promo
- **Préférences** : thème clair / sombre et choix d'affichage (liste ou
  cartes), sauvegardés en local

---

## Stack technique

- HTML / CSS / JavaScript vanilla
- [Leaflet](https://leafletjs.com/) pour la carte interactive
- Font Awesome pour les icônes

---

## Lancer le projet

Aucune installation nécessaire : c'est un site 100 % statique.

```bash
git clone https://github.com/RemiPIERRE/Promo_ENI.git
cd Promo_ENI
# ouvrir index.html dans un navigateur, ou servir le dossier avec un petit
# serveur local (ex: npx serve, ou l'extension Live Server de VS Code)
```
