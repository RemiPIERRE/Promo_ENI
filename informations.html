Description

La formation Développeur Web et Web Mobile (DWWM) est proposée par l'école ENI dans le cadre d'un cursus en ligne, financé par France Travail.


Au programme : les fondamentaux du web avec HTML, CSS et JavaScript, les frameworks Bootstrap et Angular, le développement back-end avec Symfony, ainsi que la gestion de bases de données avec MySQL.


La formation s'organise en rushs d'une à deux semaines, rythmés par des projets bilans permettant de mettre en pratique les connaissances acquises dans chaque langage. Elle se conclut par un stage en entreprise de deux mois, suivi d'une soutenance orale devant un jury comme examen final.
